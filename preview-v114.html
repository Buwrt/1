标签页按返回 → 回到首页

githup 1.1.4 · versionCode 1001004
改之前
在「探索」按返回 → 再按一次退出
稍不留神多按一下，App 就没了。
改之后
在「探索」按返回 → 首页 → 再按返回 → 再按一次退出
先回主界面，想退出再按一次。

返回键的完整优先级

顺序拦到谁动作
1图片查看器关掉查看器
2弹层 / 确认框 / 菜单关掉弹层（强制更新弹层除外，它要吞掉返回键）
3纵向层级（详情 / 议题 / Release…）逐级退回上一层
4停在某个标签页上回到首页（本次改动）
5已经在首页交给「再按一次退出」

改的代码

App.handleBack() 里加了第 4 步：

var here = (location.hash || '#/').replace(/^#/, '').split('?')[0];
if (here !== '' && here !== '/') {
  Router.go('/');
  return true;
}
return false;    // 就在首页，交给「再按一次退出」

用 Router.go('/') 而不是 history.back()：横向切标签走的是 replaceState，history 里根本没有标签之间的条目可退（上一版刚这么改的）。
